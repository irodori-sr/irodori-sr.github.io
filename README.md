# 障害福祉事業所 運営健康診断

GitHub Pagesで無料公開できる、静的なLP兼診断サイトです。

## 入っているもの

- スマホ対応LP
- 10問の運営健康診断フォーム
- 点数と改善ポイントの自動表示
- 問い合わせ導線
- 営業メール、名刺裏、A4両面ミニLPに流用できる文言

## 公開前に変更するところ

`index.html` の下の方にある「メールで相談する」ボタンのリンク先を、実際に使うメールアドレスに変更してください。

変更前:

```html
href="mailto:?subject=..."
```

変更後の例:

```html
href="mailto:info@example.com?subject=..."
```

## GitHub Pagesで無料公開する手順

1. GitHubで新しいリポジトリを作成します。
   - 例: `hukushi-check`
   - 公開用なら `Public` を選びます。

2. このフォルダのファイルをリポジトリへアップロードします。
   - `index.html`
   - `styles.css`
   - `app.js`
   - `assets/hero-operations-check.png`
   - `README.md`

3. GitHubのリポジトリ画面で `Settings` を開きます。

4. 左メニューの `Pages` を開きます。

5. `Build and deployment` の設定を次のようにします。
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`

6. `Save` を押します。

7. 数分待つと、次のようなURLで公開されます。

```text
https://ユーザー名.github.io/hukushi-check/
```

## 独自ドメインを使う場合

あとから独自ドメインを設定できます。

例:

- `hukushi-check.jp`
- `hukushi-shindan.jp`
- `tsuchida-sr.com`

GitHub Pagesの `Custom domain` に取得したドメインを入れ、ドメイン管理画面でDNS設定をGitHub Pages向けに変更します。

## A4両面ミニLPに流用する基本文言

### 表面

社長が安心して、利用者支援に集中できる事業所へ。

処遇改善加算、給与計算、労務管理、社会保険、助成金。
「あとでやろう」が一番危険です。

まずは約3分の運営健康診断で、今の状態を確認してみませんか。

### 裏面

確認できること:

- 処遇改善加算
- 給与計算
- 勤怠管理
- 社会保険手続き
- 就業規則・雇用契約
- 労務相談
- 助成金
- 実地指導・監査準備
- 指定申請・変更届
- 行政書士・弁護士との連携

最後に:

まずは「これ相談していいのかな？」という内容からお気軽にご相談ください。

supported by つちだ社会保険労務士事務所
